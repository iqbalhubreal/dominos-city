DOMINO CITY - SPLIT PROJECT

Files
- index.html: application markup and the Three.js import map.
- styles.css: all original page styles.
- js/app.js: original Three.js scene, domino simulation, camera, audio, and recording logic.

Run
1. Keep this folder structure intact.
2. Open this folder in a code editor.
3. Start a local web server (for example, VS Code Live Server).
4. Open index.html through that local server.

The app uses Three.js ES modules loaded from the CDN URLs in the import map, so it should be served over HTTP rather than opened as a file URL. Internet access is required for those CDN imports.
